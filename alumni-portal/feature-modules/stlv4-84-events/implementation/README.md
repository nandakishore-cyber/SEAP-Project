# Implementation

The complete handoff source is under
`implementation/src/main/java/com/alumni/portal/`.

It includes the event controller, service, entities, request and response
DTOs, repositories, and shared authentication classes needed for integration.

Primary endpoints:

- `GET /api/events`
- `POST /api/events`
- `POST /api/events/{id}/registrations`
- `GET /api/events/registrations/me`
